# King of Dhaka Streets Implementation Plan

**Goal:** Deliver a playable mobile-oriented browser game with five vehicles, a distinctive Dhaka street, sound and reviewed gameplay.
**Architecture:** Pure simulation separated from Three.js rendering and DOM interface. Original procedural assets and compact audio. Evaluators review independent checkpoints.
**Tech Stack:** TypeScript, Three.js, Vite, Vitest.
**Spec:** docs/design.md

## Global constraints
- Chase camera, mobile touch controls, keyboard fallback.
- Preserve authentic Bangla text; synthetic audio must not be described as recorded actors.
- Real-phone performance remains unverified until tested on physical phones.
- All five advertised vehicle types must be playable through progression.

## Tasks
- [x] Simulation: vehicle profiles, deterministic traffic, collision cooldown, horn hierarchy, clean passes, success/failure, tests. Delegate isolated module and tests to implementation agent.
- [x] Presentation: original vehicle models and animated rider, merged static streetscape, landmark, warm lighting, readable hazards and dynamic resolution.
- [x] Game shell: start screen, ride selector, touch/keyboard controls, HUD, pause, results, settings and resilient local progress.
- [x] Audio: synthesized environmental sounds, user-activated audio, optional synthesized Bangla voice files with captions.
- [x] Verification: typecheck/build/tests; start, steer, brake, horn, pause/resume and retry in browser; mobile viewport inspections.
- [x] Evaluator review: collect critical feedback, implement fixes, rerun relevant checks and record known limits.

## Interfaces
Simulation interface specified with the implementing agent before renderer integration. World consumes readonly simulation state and exposes render(dt), resize(), and vehicle selection. Input events alter simulation input only. UI reads state, dispatches start/pause/horn actions and persists unlock index/best scores after success.

## Acceptance
The landing screen starts a genuine 3D ride. Traffic moves and can collide; steering and braking change outcome; finish unlocks the next vehicle; failed trips can retry immediately; mute and pause behave consistently; build/test pass; evaluator issues addressed or clearly disclosed.

## Delivery status
The first playable acceptance checks are met. AAA finish, broader Dhaka content, native voice review and physical-phone validation remain future milestones, recorded in docs/evaluation.md.
